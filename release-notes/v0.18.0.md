## Dev-tooling hardening — ruff + mypy strict

Code-quality gates land: ruff (lint + format) and mypy (`strict=true`) run in CI and on every commit via pre-commit hooks.

### Highlights

- **Ruff lint + format gate.** New `[tool.ruff]` config in `pyproject.toml` (rules `E, W, F, I, B, UP, N, SIM, RUF`; line-length 120; `target-version = py313`). CI step in `.github/workflows/test.yml` runs `ruff check` + `ruff format --check` on every push/PR; pre-commit hook runs the same command on every commit.
- **Mypy typecheck gate, ratcheted incrementally** across four PRs so the surface broke only locally:
  1. Add mypy with non-strict config + fix all surfaced errors. CI typecheck job + pre-commit hook gating every commit. `platform=linux` pinned in mypy config for consistent `sys.platform` narrowing across CI and local.
  2. `disallow_untyped_defs` + `disallow_incomplete_defs` + `disallow_untyped_calls`.
  3. `disallow_any_generics`.
  4. `strict=true`.
- The full suite (`packages apps scripts jarvis_cli.py jarvis_gui.py`) now type-checks under strict mode in both CI and pre-commit.

### Compatibility

No runtime behaviour changes. Pure dev-tooling. Contributors need `uv sync --extra dev` to get the pre-commit hooks; they fire automatically once `uv run pre-commit install` runs.

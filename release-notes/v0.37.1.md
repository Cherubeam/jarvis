## Shared context files, and a docs refresh

No code changes in JARVIS. This release covers Cortex v0.8.0 and brings the docs up to date.

### Changed

- **Specialists can read your context files.** Cortex's new opt-in `read_context` tool arrives through the shared MCP server. Only the main agent has these files in its prompt, so Navigator, the writer and the others get access for the first time. To enable it, name the files under `context_files` in Cortex's `config/local.yaml`. Every connected tool and its model provider can then read them.

### Fixed

- Roadmap status of AON-02 and HUB-02, the Cortex tool lists, the scripts tree and the README feature list now match what shipped.

### Live checks

- `read_context` verified over a real stdio connection to `cortex-mcp`: four configured files returned, an unconfigured name refused.
- Not run live: an agent choosing the tool on its own.

## GUI approvals reach the running turn

A vault write approved in the GUI no longer hangs, and every write asks for its own approval.

### Fixes

- **Approvals and cancels reach a running turn.** The WebSocket loop waited for the turn while the turn waited for the approval; neither moved until the tab closed, and the write counted as rejected. The turn now runs as its own task. Three WebSocket tests reproduced the hang first.
- **Every write asks again.** A second vault write in the same turn reused the first decision without showing its card. State now resets per approval; a decision for an old id is refused.
- **An unanswered approval is rejected after 10 minutes.** Human oversight (EU AI Act Art. 14(4)); OWASP LLM06.

### Tests

**2,860 collected** (2,854 in v0.30.0).

### Known limits

- The fix was found by reading the code and confirmed with tests; it hasn't been exercised live in the GUI yet.

## Model Control

You decide which model does what, and you can see which one did it.

### Highlights

- **Agents can name their own model.** `meta.yaml` accepts `model:` with a preset or a model id, and the agent runs its whole turn on it: tool loop, final answer and pricing. `writer` and `substack_publisher` now run on `quality` (Opus 5.5); content_reviewer and developer stay on the default. The router's hard-coded "quality agents" list is gone. Before, it only applied to the top-level agent and never to delegated ones.
- **OpenRouter Auto Router as an opt-in mode** (`models.auto_router`, off by default; also `/model auto`). OpenRouter picks the model per turn. JARVIS shows `auto → <model>`, logs it as `metadata.served_models`, and bills the exact reported cost; LiteLLM prices auto at $0, so the price table would have shown every auto turn as free. Auto turns don't stream, because LiteLLM drops the model and its cost from streams. On the golden suite, auto scored 13/15 against GPT-6 Luna's 15/15, so it stays opt-in. See ADR-036.
- **The writer tags its prose.** It adds `prose` to a note's `assist:` frontmatter list when it writes sentences into it, so assisted text stays out of voice-profile work.
- **One topic, one home in the docs.** About 2,000 duplicated lines were removed; 15 of them already contradicted each other. Every topic is now described in one doc and linked from the others. The rule is in AGENTS.md.
- **Smaller fixes:**
  - An agent's `max_tokens` no longer sticks to later turns.
  - `evaluate_content` follows the running agent's model.
  - `LLMClient.complete()` handles low-credit (402) errors, so the reduced-output retry works on the non-streaming path too.

Framework hooks: EU AI Act Art. 12 (record-keeping of which model answered; applied voluntarily).

### Tests

**2,894 collected** (+39).

### Compatibility

- **Writer and substack_publisher now cost more per turn** because they run on Opus 5.5. Remove `model: quality` from their `meta.yaml` to go back to the session model.
- **Non-streaming OpenRouter costs** now use the provider-reported billed amount. That's more accurate, but numbers change for `models.streaming: false` users.
- **Internal:** `route_query()` / `classify_query()` lost their `agent_name` parameter. `TokenUsage` has a `reported_cost` field and `__add__`; `StreamResult` has `served_models`.

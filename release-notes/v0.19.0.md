## GUI Productivity — Phases 5–7

Agent-centric workflows in the browser: agents overview, in-GUI prompt editing with snapshot history, and outcome scoring + daily-summary handlers.

### Highlights

- **Phase 5 — Agents Overview + Detail.** Categorized grid (Writing / Knowledge / Planning / Analysis / Generation / Engineering); JARVIS featured as orchestrator. Agent Detail with tool list, recent sessions, **14-day cost sparkline**, "start session →" launcher. New `GET /api/agents/{id}` re-parses `meta.yaml` to surface `temperature`, `max_tokens`, `max_iterations`, `prompt_includes`. JARVIS special-cased (registry skips it; route returns `prompt_path: null`).
- **Phase 6 — Agent Prompt Editor.** Activates the greyed tab row from Phase 5: **Prompt · Versions · Stats · Context**. 7 routes under `/api/agents/{id}/prompt*`. Microsecond-resolution snapshots + `index.json` sidecar with directory-glob fallback. Per-agent `asyncio.Lock` serialises read-snapshot-write. `kind ∈ {save, pre_first_save, pre_restore}` so first-save and pre-restore are auto-protected. JARVIS read-only (writes return 403). Resolved-prompt preview shows the LLM-eye view with `{placeholder}`-expanded includes.
- **Phase 7 — `/daily-summary` and `/outcomes` GUI handlers.** New `packages/core/daily_summary.py` (request builder) + promotion of `apps/cli/review.py` underscore-private helpers to public. Backend `apps/gui/server/routes/outcomes.py` with `GET /api/outcomes/pending` + `POST /api/outcomes/{file_id}/review`. Bridge forks `/daily-summary` to a streaming-aware `_run_daily_summary_turn`. Frontend `OutcomesView` with inline scoring cards.

### Tests

23 + 54 + 43 = **120 new tests** across Phases 5–7. Suite moves from 1,935 → 2,066 pass.

### Compatibility

No breaking changes. The new GUI surfaces sit alongside the existing Phases 1–4 surfaces.

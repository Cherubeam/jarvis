## GUI Conversation Lifecycle — hard-delete + resume

Three small, focused features that close the long-standing "I have to drop into the filesystem to manage conversations" gap. Test sessions can be deleted; past conversations can be resumed in-place from either the chat sidebar or the History detail pane.

### Highlights

- **Hard-delete a conversation from the History detail pane.** New red `delete` button next to `resume` / `export` opens a confirm dialog, then fires `DELETE /api/conversations/{id}` — unlinks the JSON, evicts the in-memory `ConversationIndex` cache entry, and (when `rag.enabled`) removes the conversation's chunks from the ChromaDB recall collection so semantic search stops surfacing it. 409 guard refuses to delete the currently-active session's file. Sidebar / Home / Agent-detail all re-fetch on success.
- **Resume a past conversation from the chat sidebar.** Clicking a row no longer yanks you to the History view (which was the confusing prior behavior). Instead, the conversation loads into the live chat stream and your next message appends to the *same* JSON file. New WS protocol message `{"type": "resume", "file_id": "<stem>"}` handled by a new `apps/gui/server/resume.py` module that reads the JSON, mutates the active `ConversationLogger` in place via the new `rehydrate(messages, session_start, conversation_id, metrics)` method, and emits synthetic replay events (`user` / `text` / `tool_call`) so the chat view paints the prior turns. Sidebar grays out + refuses clicks during in-flight turns; composer-draft warning fires when the user has unsent text.
- **History detail-pane `resume →` button now actually resumes.** Reuses the same WS protocol as the chat sidebar via a new `pendingResumeId` race-guard in `App.tsx` (mirrors the existing `pendingSeed` pattern from Home's Quick Start). Click the button → switch to chat → ChatView consumes the pending id after `wsReady` and emits the resume message. Stale `title="Resume is deferred"` tooltip + 0.7-opacity styling removed.

### Tests

Final test count: **2,215 collected** (2,203 pass, 12 skipped — golden tests gated behind `--evaluate`). The lifecycle work added **24 new tests** across `test_history_index.py`, `test_conversations_route.py`, `test_rag_indexer.py`, `test_memory.py`, and the new `test_resume.py`.

### Compatibility

No external API changes. Internal: `ConvDetailPane`'s `onResume` prop went from `() => void` to `(fileId: string) => void`; consumed only by `HistoryView`, no other callers. `ChatView` no longer accepts `onOpenHistory` — the chat sidebar's row click is now a chat-internal resume action, not a navigation. Pre-1.0 minor bumps may include this kind of internal change per the release policy.

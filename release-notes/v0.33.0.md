## Conversation recall through Cortex

One index for past conversations: JARVIS, Claude Code and any other MCP client search the same archive through Cortex. JARVIS's own conversation index is gone.

### Highlights

- **Recall comes from Cortex** (HUB-02). JARVIS uses `mcp_cortex__search_conversations` through the shared `cortex` MCP server (needs Cortex v0.4.0 with `sources.conversations` enabled). It covers native JARVIS sessions plus imported Claude, Claude Code and ChatGPT conversations, with filters for date range and origin and up to 20 results.
- **Better exchanges.** An exchange now keeps all assistant text up to the next user message; the old index lost answers that followed a tool call, such as ChatGPT browsing.
- **Fresh within seconds.** Cortex's file watcher indexes a saved or resumed conversation right away and drops a deleted one. JARVIS no longer embeds anything at startup.
- **Scope of exposure is set in Cortex:** off unless enabled, its own collection, client-work projects excluded (OWASP LLM02:2025; NIST AI RMF Manage). Claude.ai conversations carry no project, so client work there stays indexed; the owner chose that for now.

### Removed

- `recall_conversations`, `packages/core/rag/indexer.py`, `searcher.py`, `embed_limits.py` and their tests (−2,168 lines). The local RAG store keeps outcomes and deck cards; its old `conversations` collection was deleted.

### Fixed

- **No more "disconnect error" on every exit.** MCP connections were opened in one asyncio task and closed in another, which anyio forbids. Each connection now lives in one task. A new test fails on the old code.

### Tests

**2,823 collected** (2,896 in v0.32.0; the removed recall modules took their tests with them).

### Live check

The first real question ("What did we decide about the conversation index last week?") made JARVIS call the tool 5 times with correct date filters. It used about 90,000 tokens: a 5-result call returns about 2,300 tokens, more than the old 6,000-char cap. That's not capped yet; watch it in the cost baseline.

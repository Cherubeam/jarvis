## GUI Configuration — Phase 8 + follow-ups

Typed `pydantic-settings` configuration end-to-end, the in-GUI Settings editor, field-level hot-apply gating, and the prompt-include editor.

### Highlights

- **PR-8a — pydantic-settings migration.** Replaces `apps.cli.main.load_config() -> dict[str, Any]` with `packages.core.settings.load_config() -> Settings`, a typed `pydantic-settings` model covering all 16 top-level YAML sections. 21 rollback-safe commits, each green under `pytest`/`mypy`/`ruff`. 63 call sites across 17 files migrated. `MCPServerConfig` + `parse_mcp_config` + `ImageGenerationConfig` consolidated into the typed model. See [ADR-032](https://github.com/Cherubeam/jarvis/blob/main/docs/product/decisions.md#adr-032-adopt-pydantic-settings-for-typed-configuration).
- **PR-8b — Settings GUI view.** 2-pane left-nav editor for all 16 sections (not a 16-wide tab bar — flat tabs at this scale are a known UX anti-pattern). `GET /api/settings`, `GET /api/settings/schema` (fully dereferenced — no `$ref`), `PUT /api/settings` with atomic write + **managed-header guard** (409 if overwriting hand-crafted `local.yaml`). Validation-error normalisation with `card_loc` + `kind ∈ {field, model_validator}`. Reusable `ScalarPanel` for 12 sections + bespoke `Obsidian` / `PatternCards` / `McpServers` / `Filesystem` panels. Inline `(?)` tooltips from pydantic descriptions.
- **Field-level hot-apply gating.** New `classify_changes()` + `HOT_APPLY_PATHS = {"summarization", "paths.prompt_history_dir"}` whitelist. `PUT /api/settings` rebinds `session.components.settings` on save (preserving runtime `jarvis_dir`). Footer renders four variants based on what the save bucketed: no changes / hot-only / cold-only / mixed. Whitelist-not-metadata (rebind contract documented in ADR-032 third addendum).
- **Prompt-include editor (Phase 6 follow-up).** New `Includes` tab on agent detail (hidden when `prompt_includes_count === 0`). Six routes under `/api/agents/{id}/includes*`. Status badges (local / shared / example / missing). Shared writes require explicit modal confirm + `affects_agents: [...]` warning bar. Per-`(agent, placeholder)` snapshots reuse `prompt_history.py` via slash-encoded keys. Restore writes to currently-resolved file (pinned by test).

### Cleanup

- Deleted `packages/core/app.py` (139 LOC, zero importers, latent shallow-merge bug) and `packages/integrations/mcp/config.py` — both superseded by the typed Settings module.
- Rail-icon polish: swapped `Agents` icon (tool → users) and `Settings` icon (note → sliders).

### Tests

Final test count: **2,174 pass**. Settings work added 62 + 32 + 16 + 29 = 139 new tests across the 4 PRs.

### Compatibility

**Internal API change**: `apps.cli.main.load_config()` now returns a `Settings` instance instead of `dict[str, Any]`. The `apps.cli.main` re-export is retained for back-compat, but type hints differ. No external scripts depended on this signature; pre-1.0 minor bumps may include this kind of change per the release policy.

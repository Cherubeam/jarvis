## Spend limits and Personal Intelligence

JARVIS now has a dollar limit on every turn and every month, and it can read your career direction map from the Personal Intelligence app. This release also closes AON-01, the hardening milestone.

### Highlights

- **Per-turn limit** (`budget.max_turn_usd`, default $1.00). Both tool loops stop before their next model call once a turn has cost that much. The work so far is kept, and your next message continues with a fresh allowance.
- **Monthly limit** (`budget.monthly_usd`, default $20). You get one notice per session at 80%. Above the limit, the CLI asks once per session whether to continue (human oversight, EU AI Act Art. 14); the GUI shows a notice and continues.
- **Cost ledger.** One JSON line per turn in `budget.ledger_dir/YYYY-MM.jsonl` (record-keeping, Art. 12). The content evaluator and history summarizer now record their own spend, which never appeared in a turn's cost before. The limits count streamed estimates at 1.5×, because they run about 36% low until the bill arrives.
- **Personal Intelligence over HTTP** (HUB-04, [ADR-042](https://github.com/Cherubeam/jarvis/blob/main/docs/product/decisions.md#adr-042-personal-intelligence-over-http-not-mcp)). `career_direction_map` and `suite_health` read the app's API with its Bearer token. They're off by default: set `personal_intelligence.enabled` in `local.yaml`. LLM-written theme names are labelled as hypotheses (Art. 14), and snapshot text is fenced as untrusted data (OWASP LLM01).

### Changed

- Cortex's HTTP API now requires a token (suite threat model TM-01). JARVIS needs no code or config change; the deployment guide says where the token lives.
- The GUI settings page has a Budget section.
- AON-01 is complete. Three items stay open on purpose: the OpenRouter data policy (deferred), the deterministic stop condition (waits for the first unattended job) and a GUI budget card (backlog).

### Live checks

- Budget: one GUI turn on GPT-6 Luna wrote a correct ledger line, and the Budget section renders.
- Personal Intelligence: one JARVIS turn on GPT-6 Luna chose the tool on its own. In that run the model did not label theme names as hypotheses, so that's one to watch.
- Not run live: a turn hitting the $1 limit, the CLI prompt over the monthly limit, and the degraded-map and injection paths. Those are covered by unit tests only.

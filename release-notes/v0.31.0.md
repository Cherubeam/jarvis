## Claude Code sessions in the archive

Claude Code sessions join the conversation archive, and conversation search keeps up with conversations that grow.

### Highlights

- **`scripts/import_claude_code.py`** imports Claude Code transcripts: one turn per typed prompt, harness-injected lines skipped, slash commands kept as `/name args`. Tool calls stay as one-line summaries; tool output becomes a size stub, so search finds what was said, not file dumps. Titles come from the desktop app's session list.
- **Subagent reports are kept verbatim**, whether the subagent ran in the foreground or the background. The subagent transcripts themselves are counted, not imported.
- **Conversation search re-embeds pairs that were added or changed.** Each pair carries a `doc_hash`; turns added by a resumed session or a later import become searchable instead of being skipped forever. Pairs indexed before this release are trusted, with no bulk re-embed.
- Token usage of imported turns goes into metadata, never `usage`, so imports don't count as JARVIS spend.

### Tests

**2,918 collected** (2,860 in v0.30.1).

### Live check

123 sessions imported (2,207 messages); 92 of 92 desktop titles matched. The first JARVIS start indexed 127 conversations: the 123 sessions plus 4 Claude conversations that had grown since they were indexed.

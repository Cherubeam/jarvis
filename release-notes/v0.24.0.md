## Model Refresh & Vault Oversight

Nothing changed in JARVIS's code, and yet `/review` stopped working. Via OpenRouter, the default model (Qwen 3.5 Flash) had started returning its reasoning as the answer. Fixing that grew into a model refresh. Along the way, three gaps turned up where a vault-write approval could show you something other than the real change.

### Highlights

- **Per-model request fields (`models.extra_body`).** The first use turns Qwen 3.5 Flash's reasoning off (`reasoning: {effort: "none"}`), which fixed the leak.
- **A 10-model benchmark with two judges.** Each model got 15 golden results, judged by Opus 5.5, with Gemini 3.8 Flash as a second judge on the conversation tests.
  - **GPT-6 Luna** is the new default and `balanced`/`fast` preset: 15/15 passed, 0.907 average, 3 s median, about $0.00014 per request.
  - **Opus 5.5** is the new `quality` model: 15/15, 0.923.
  - This also retires `google/gemini-2.5-flash` before OpenRouter drops it on 2026-10-20.
  - Full tables and the method are in `docs/research/models.md`.
- **The GUI approval card shows the real diff.** It had been showing an object dump with an empty path, so GUI approvals were given without a readable diff.
- **Link changes are listed above every vault diff.** A one-character URL change can no longer hide in a long rewrite.
- **No more silent reverts.** Read tools record what the agent saw. A write or preview is refused when the note changed on disk since then, and re-checked after approval.
- **Tool-limit note.** When an agent runs out of tool rounds, it's told the tools still exist instead of concluding they're missing. content_reviewer gets 10 rounds.
- **Golden harness fixes.**
  - Multi-turn tests now send the conversation history and score each turn.
  - The judge comes from `evaluation.judge_model`.
  - Output is capped so runs survive a low OpenRouter balance.
  - New `required_verbatim` checks, plus two writing cases.
- **Routed turns are priced at the routed model's rates.**

Framework hooks: EU AI Act Art. 14(4)(c) for the approval-gate fixes (applied voluntarily; JARVIS isn't a high-risk system), OWASP LLM05 Improper Output Handling and LLM06 Excessive Agency, and NIST AI RMF *Measure* for the benchmark.

### Tests

**2,855 collected** (+45). The 5 tests that describe the stale-write bug fail without the fix.

### Compatibility

- **Default model and presets change** to GPT-6 Luna, with Opus 5.5 as `quality`. Overrides in `config/local.yaml` still win.
- **The golden judge is now `anthropic/claude-opus-5.5`,** read from config. April's benchmark scores aren't comparable, because the multi-turn test was broken then.
- **`approval_pending` WebSocket events** carry a new `link_warnings` field.

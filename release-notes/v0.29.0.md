## What JARVIS is for, and data out of the repo

Two decisions, and the work that follows from them: JARVIS is an owned daily assistant and a place to learn, and every kind of data now has one home outside the code repo.

### Highlights

- **[ADR-040](https://github.com/Cherubeam/jarvis/blob/main/docs/product/decisions.md#adr-040-what-jarvis-is-for--an-owned-daily-assistant-and-a-place-to-learn): what JARVIS is for.** An owned, local-first daily assistant and a platform to learn and show work. It is the central archive for conversations imported from other AI tools, with a Dots-like personal assistant as the north star. The commodity argument of ADR-034 now covers coding harnesses only. `vision.md` and the roadmap's new "Current focus" order follow.
- **[ADR-041](https://github.com/Cherubeam/jarvis/blob/main/docs/product/decisions.md#adr-041-where-each-kind-of-data-lives): where each kind of data lives.**
  - Notes and memory live in the Obsidian vault, and tasks in Things 3.
  - Conversations and other machine data live in a data home outside every repo.
  - Indexes and caches stay local and unsynced, because they can be rebuilt and a synced database gets corrupted.
  - Imports propose changes for approval instead of overwriting (human oversight, EU AI Act Art. 14).
- **Data paths follow the settings everywhere.** Scripts and importers read `paths.*`. The GUI token file is a setting (`gui.token_file`), and the token itself still never enters Settings.
- **Conversation files are written atomically:** to a temporary file first, then swapped into place, so a crash or full disk never leaves half-written JSON, and iCloud never uploads a partial file (record-keeping integrity, Art. 12).
- **Conversation search no longer switches itself off.** Chunks were measured in characters, and dense text (code, JSON, German) exceeded the embedding model's 8,191-token limit. JARVIS then disabled recall for the whole session. Chunks are now measured with the model's own tokenizer.
- **Outcome writes work again** once outcomes have their own access rule. A `local.yaml` that replaced the whole access-rule list had dropped the default rule for `data/outcomes`.
- **The deep-research dossier is revised for September:** a refreshed audit, a decision-model evaluation (Jev), and a roadmap that was trigger-scored, attacked by a skeptic and pre-mortemed.

### Tests

**2,822 collected** (2,789 in v0.28.0). New tests cover atomic saves keeping the last good copy on a failed write, path settings for every script, the token-file location with an absolute path containing a space, and token-based chunking, with a regression case for dense text under the old character limit.

### Known limits

- A conversation updated by a later import is not re-indexed, so its new messages are missing from recall.
- GUI vault approvals likely hang mid-turn (read from the code, not reproduced). Tracked in AON-01.
- Do not run `scripts/import_claude_context.py`. It overwrites context files and reads an outdated export format; a proposal-based replacement is planned (HUB-03).

# Obsidian Vault Writing Conventions

When writing content for an Obsidian vault, follow these rules:

## Formatting

- Use standard Obsidian-flavored markdown
- Use `[[wikilinks]]` for internal links to other notes
- Use `#tags` sparingly — prefer wikilinks for connections
- Use callout blocks (`> [!type]`) for structured content

## JARVIS Callout Block

- All JARVIS-generated content goes inside `> [!JARVIS]` callout blocks
- Never write outside the designated callout block
- Preserve all existing content in the note — only append within the block

## Tone

- Write concisely and clearly
- Match the user's writing style where possible
- Avoid filler words and unnecessary qualifiers
- Use active voice

## Safety

- Never delete or modify existing note content
- Always show a diff before writing
- Require explicit confirmation before any write operation

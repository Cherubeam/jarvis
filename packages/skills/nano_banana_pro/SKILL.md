# Nano Banana Pro — Image Prompt Generator

## What This Does
Generates detailed, production-ready image prompts for AI image generators
(Midjourney, DALL-E, Flux) that follow The Technical Humanist visual brand
guidelines. Produces prompts that create consistent, recognizable imagery
across all content.

## When to Use This
- Creating header images for blog posts or newsletters
- Generating social media visuals for The Technical Humanist
- Producing consistent branded imagery across platforms
- When you need a prompt that captures a specific concept visually

## What to Expect
- A detailed image generation prompt with style, composition, and mood
- Consistent brand elements (color palette, aesthetic, tone)
- Prompt formatted for direct use with image generation tools
- Explanation of creative choices made

## Boundaries
Does NOT generate images directly — outputs text prompts only
Does NOT modify or edit existing images
Does NOT create prompts for non-TTH brand imagery
Does NOT provide graphic design or layout advice

## How to Invoke
Describe the concept, topic, or mood you want the image to convey.
Optionally specify the target platform (blog header, social media, etc.)
and any specific elements you want included.

## Brand Guidelines
- Aesthetic: Clean, minimal, human-centered technology
- Mood: Thoughtful, warm, accessible — not cold or corporate
- Colors: Warm neutrals with selective accent colors
- Style: Editorial illustration meets tech — never stock-photo generic
- Composition: Generous whitespace, single focal point
